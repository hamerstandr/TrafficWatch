# TrafficWatch - مانیتور ترافیک شبکه

## بررسی کلی
TrafficWatch یک برنامه مانیتورینگ ترافیک شبکه برای ویندوز است که امکان نظارت بلادرنگ بر استفاده از شبکه، تحلیل ترافیک در سطح فرآیند و ردیابی داده‌های تاریخی را فراهم می‌کند.

## ویژگی‌ها
- **مانیتورینگ بلادرنگ**: نمایش لحظه‌ای سرعت دانلود و آپلود
- **ردیابی فرآیندها**: نظارت بر ترافیک شبکه به تفکیک هر فرآیند
- **داده‌های تاریخی**: ردیابی آمار روزانه، ماهانه و کل ترافیک
- **داشبورد وب**: دسترسی به آمار ترافیک از طریق سرور وب داخلی (اختیاری)
- **یکپارچه‌سازی با سیستم تری**: اجرای آرام در پس‌زمینه
- **پشتیبانی از چند دسکتاپ مجازی**: کار در دسکتاپ‌های مجازی (ویندوز 10+)
- **پشتیبانی از تم**: دنبال کردن رنگ‌های تم سیستم ویندوز
- **رابط کاربری سه زبانه**: فارسی، انگلیسی و عربی

## نیازمندی‌ها
- **سیستم عامل**: ویندوز 7، 8، 10 یا 11
- **.NET Framework**: نسخه 4.7 یا بالاتر
- **WinPcap**: مورد نیاز برای ضبط بسته‌های شبکه (اختیاری - برای قابلیت‌های پیشرفته)
- **کارت شبکه**: رابط شبکه فعال برای مانیتورینگ

## استفاده

### اجرای برنامه
1. فایل `TrafficWatch.exe` را اجرا کنید
2. برنامه شروع به مانیتورینگ ترافیک شبکه می‌کند
3. پنجره اصلی را برای آمار بلادرنگ مشاهده کنید
4. داشبورد وب را در مرورگر باز کنید (در صورت فعال بودن)

### داشبورد وب
سرور وب داخلی این امکانات را فراهم می‌کند:
- سرعت لحظه‌ای دانلود/آپلود
- آمار تاریخی (روزانه، ماهانه، کل)
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- بروزرسانی خودکار هر 2 ثانیه

**نکته**: سرور وب اختیاری است و می‌توانید آن را از تنظیمات غیرفعال کنید.

### منوی سیستم تری
- **نمایش/مخفی‌کردن**: تغییر وضعیت видимیت پنجره اصلی
- **مخفی شدن لبه‌ای**: مخفی کردن خودکار پنجره در لبه صفحه
- **تنظیمات**: پیکربندی ترجیحات برنامه
- **خروج**: بستن برنامه

## نقاط پایانی API

سرور HTTP داخلی نقاط پایانی زیر را ارائه می‌دهد:

| نقطه پایانی | توضیحات |
|------------|---------|
| `/state/index.html` | داشبورد وب |
| `/Download` | سرعت دانلود فعلی |
| `/Upload` | سرعت آپلود فعلی |
| `/MaxSpeed` | حداکثر سرعت ثبت شده |
| `/Daydownload` | مجموع دانلود امروز |
| `/Dayupload` | مجموع آپلود امروز |
| `/Monthdownload` | مجموع دانلود ماه |
| `/Monthupload` | مجموع آپلود ماه |
| `/Totaldownload` | مجموع کل دانلود |
| `/Totalupload` | مجموع کل آپلود |

## عیب‌یابی

### WinPcap یافت نشد
اگر خطای WinPcap دریافت کردید:
1. WinPcap را از سایت رسمی دانلود کنید
2. با دسترسی مدیر نصب کنید
3. برنامه را مجدداً راه‌اندازی کنید

### ترافیکی نمایش داده نمی‌شود
- اطمینان حاصل کنید که اتصال شبکه فعال دارید
- برنامه را با دسترسی مدیر اجرا کنید
- بررسی کنید که کارت شبکه صحیح انتخاب شده باشد

### داشبورد وب بارگذاری نمی‌شود
- بررسی کنید که برنامه در حال اجرا باشد
- اطمینان حاصل کنید که پورت 8080 آزاد باشد
- سرور وب را در تنظیمات فعال کنید
- آدرس `http://localhost:8080/state/index.html` را امتحان کنید
